## Installing Java on MacOS

It does not use the `PATH` environment variable.  MacOS expects JDKs to be placed in `Library/Java/JavaVirtualMachines/<jdk-instance>`.

## Packages and Modules

Packages names (`package.subpackage.compilationunit`) are converted into pathnames by replacings `.`s with a filesystem separator character like `/`.  When using the filesystem instead of a database to store packages, this allows lookup of compilation units.
